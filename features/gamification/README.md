## กติกาที่ user ตัดสิน 2026-08-24

**1. ภารกิจอยู่แท็บเดียว ไม่ซ้ำสองที่**

ทำครบเงื่อนไขแล้ว → ย้ายไป `สำเร็จแล้ว` และหายจาก `ทั้งหมด` ทันที
(สอดคล้องกับ ux §4.1 ที่ให้แท็บนั้นเป็น "ประวัติว่าทำอะไรจบไปแล้วบ้าง")

**2. ไม่มีสถานะ "หมดเวลา" ของภารกิจ**

ทุกภารกิจใช้ช่วงแคมเปญเดียวกัน 3 เดือน — ภารกิจเดี่ยวๆ หมดเวลาเองไม่ได้
พอหมดก็หมดพร้อมกันทั้งหมด ซึ่งคือ **แคมเปญจบ** ไม่ใช่ภารกิจหมดอายุ

ภารกิจปิดได้ทางเดียวคือ **ของรางวัลหมด** → CTA เหลือ **4 สถานะ** ไม่ใช่ 5

> ⚠️ **เอกสารยังขัดกันอยู่ ต้องแก้**
> - `prd-dev.md §5.2` ใส่ `EXPIRED` ไว้ใน state machine ของ *ภารกิจ*
> - `tickets.md` **AC6** เขียนว่า CTA มี 5 สถานะ รวม "หมดอายุ" · **AC2** จัดกลุ่ม "ของหมด/หมดอายุ"
> - แต่ `ux-gamification.md §2` ระบุ `MSN-921 หมดอายุ` เป็น **Stage: Reward** ผูกกับ `OPEN-13 อายุคูปอง`
>
> ตีความตามกฎที่ user ให้: `MSN-921` = **อายุของรางวัลหลังกดรับ** (คูปองหมดอายุ) ไม่ใช่ภารกิจหมดเวลา
> → ยังต้องทำ `MSN-921` อยู่ แต่มันอยู่ฝั่ง reward หลัง claim ไม่ใช่บนการ์ดภารกิจ

**3. ภารกิจมี 3 ประเภท progress ต้องวาดคนละแบบ** `[user 2026-08-24]`

Figma `2250:46164` ไม่ได้บอกแค่ตาราง tier — หัวสีเขียว/เหลืองเหนือแต่ละตารางบอก**โครงสร้าง task**
และเป็นสิ่งที่ UI รอบแรกไม่ได้ทำตาม

| กลุ่ม | Figma เขียนว่า | การ์ดวาดยังไง |
|---|---|---|
| VOLUME #1 · BEGINNER→NORMAL | `1 Mission : 3 Task ประเภทเดียวกันแบบต่อเนื่อง` | **บันได 3 หมุด มีรางวัลทุกหมุด** — 50 ใบ กล่องข้าว · 200 ใบ บัตรสตาบัค · 500 ใบ หูฟัง Sony |
| VOLUME #2 · HARD→LEGENDARY | `1 Mission : 1 Task แบบต่อเนื่อง` | **เส้นเดียว ไม่มีหมุด** |
| FREQUENCY ทั้ง 4 tier | `1 Mission : 2 Task คนละประเภท` | **2 เส้นแยกกัน** — งวด + จิ๊ดริด |

**สามตัวที่แก้เพราะเรื่องนี้**

1. **จิ๊ดริดเคยหายไปจากการ์ด** — `ภารกิจพิชิตใจจิ๊ดริด` เงื่อนไขคือ *ซื้อต่อเนื่อง 3 งวด **+** ใช้จิ๊ดริดกล่องสุ่ม 3*
   แต่การ์ดโชว์แค่ `2/3 งวด` เส้นเดียว → user ไม่มีทางรู้ว่ามีอย่างที่สองต้องทำ (นี่คือ MT-02 ที่เอกสารเขียนไว้แล้วแต่ UI ยังไม่ทำ)
2. **VOLUME ขั้นบนเคยมีหมุดที่ไม่มีจริง** — `ภารกิจเจ้าสัว` ใส่หมุด 500/1,500/3,000 ทั้งที่ Figma บอกว่ากลุ่มนี้ไม่มีหมุดย่อย
3. **คำเงื่อนไขจิ๊ดริดผิดความหมาย** — โค้ดเขียน "ลองจิ๊ดริด 1 **ประเภท**" · Figma เขียน "ใช้ Jidrid **กล่องสุ่ม 3**" คนละเรื่องกัน

**สิ่งที่ยังต้องเคาะจากการยุบ VOLUME #1 เป็นบันได**

- ชื่อ `ภารกิจเส้นทางเศรษฐี` **เขียนขึ้นเอง** ไม่มีในตาราง — รอ marketing
- `MSN-300` ต้องรับ claim เป็น "หมุดที่ N" ไม่ใช่ "ภารกิจ" → idempotency key เปลี่ยน
- รอยต่อบันได (จบ 500 ใบ) กับ VOLUME #2 (เริ่ม 1,000 ใบ) ยังไม่ได้ออกแบบ → `OPEN-21`
