## 0. TL;DR — Identity & Audience Digest

**Positioning Statement (immutable):**
> "เราคือความหวังของคนจะรวย"

**Brand Archetype:** IRONMAN = **RULER × CREATOR × HERO**
- RULER → ผู้วางมาตรฐาน (System)
- CREATOR → ผู้สร้างระบบใหม่ (Innovation)
- HERO → ผู้พิทักษ์ความหวัง (Humanity)
- สูตร = **ระบบ × นวัตกรรม × หัวใจ**

**Banned Archetypes (ห้ามใช้เด็ดขาด — ทำให้ Brand Drift):**
- OUTLAW (เราสร้างระบบใหม่ ไม่ล้มระบบ)
- JESTER (ไม่เล่นกับความหวังของคน)
- INNOCENT (ไม่โลกสวย รู้ความจริงของตลาด)
- CAREGIVER ล้วน ๆ (ไม่ใจดีแบบไร้มาตรฐาน)

**Customer Archetypes (4):**
1. **INNOCENT** — มองโอกาสเป็น "ความหวัง" · ต้องการ ปลอดภัย + โปร่งใส
2. **EXPLORER** — มองหา feature/tech ใหม่ · ต้องการ ทันสมัย + ใช้ง่าย
3. **EVERYMAN** — *กลุ่มหลักสุด* · ต้องการ ง่าย + สะดวก + ถูกต้อง
4. **OUTLAW** — ตั้งคำถามกับระบบ · ต้องการ proof ที่ตรวจสอบได้

**Common ground ทั้ง 4:** ทุก archetype ต้องการสิ่งเดียวกัน = "ความหวังที่มีความรับผิดชอบ + ระบบที่เชื่อถือได้"

**Our Winning Zone:** เป็นแบรนด์ลอตเตอรี่ที่ลูกค้ารู้จัก "เจ้าของแบรนด์" ได้, ดูแลความหวังด้วยความถูกต้อง, ประสบการณ์ง่ายและสบายใจ, ยืนข้างผู้ใช้อย่างชัดเจน

## 1. Brand Archetype — IRONMAN

ใช้กำหนด: บุคลิก / การสื่อสาร / การตัดสินใจ

### 1.1 RULER — ผู้กำหนดมาตรฐาน (System)

เป็น Ruler ไม่ใช่เพราะ "มีอำนาจ" แต่เพราะ **"ยอมรับอำนาจและไม่หนีความรับผิดชอบ"**

**Identity:**
- ผู้วางมาตรฐานความถูกต้อง
- คุมความเสี่ยงแทนลูกค้า
- รับผิดชอบต่อเงิน / ความหวัง / ความรู้สึก
- ทำให้สิ่งคลุมเครือ "ชัดและตรวจสอบได้"

**Proof-based behavior:**
- กติกาชัดเจน ไม่เปลี่ยนกลางทาง
- ระบบโปร่งใส ตรวจสอบได้
- กล้ายืนเมื่อมีปัญหา
- บริษัทรับผิดแทนลูกค้าเมื่อระบบผิด

🚫 **จะไม่เป็น:**
- ใช้อำนาจกดคน
- ใช้กฎหมายเป็นข้ออ้าง
- ใช้มาตรฐานปกป้องตัวเอง
- ปฏิเสธความผิดของตัวเอง

### 1.2 CREATOR — ผู้สร้างระบบใหม่ (Innovation)

ใช้ tech + design + ระบบ แก้ปัญหาที่เคยมีในตลาด

**Identity:**
- สร้างแพลตฟอร์มที่ไม่เคยมี
- เปลี่ยนหวยจาก "ความเสี่ยง-ไม่ชัดเจน" → "สินค้าที่ชัดเจน อุ่นใจได้"
- Prototype ต้องใช้ได้จริง ปรับได้จริง ขยายได้จริง
- สร้างโครงสร้างที่เลียนแบบยาก

**Proof-based behavior:**
- เทคโนโลยีต้องลดความเสี่ยงลูกค้า
- UX ต้องเข้าใจง่าย ไม่ใช่แค่สวย
- ระบบต้องทำงานได้แม้ในวันมีปัญหา

🚫 **จะไม่เป็น:**
- เล่นของโชว์เก่ง
- Innovation ที่เพิ่มความเสี่ยง
- ของสวยที่ไม่สร้าง Impact

### 1.3 HERO — ผู้พิทักษ์ความหวัง (Humanity)

ชั้น "ศีลธรรม" ที่ทำให้แบรนด์เป็นมนุษย์ — ถ้ามีแค่ Ruler × Creator จะเก่งแต่เย็นชา

**Identity:**
- ยืนข้างคนธรรมดา
- ดูแลความหวังเล็ก ๆ จริงจัง
- อยู่ตรงนั้นทั้งวันที่ลูกค้าดีใจที่สุดและกังวลที่สุด
- "ไม่ขายฝัน แต่ดูแลฝัน"

**Proof-based behavior:**
- Customer Service ไม่ปลอบ แต่จัดการให้จบ
- ถูกรางวัลแล้วจับต้องได้จริง
- ไม่หาย ไม่เงียบ ไม่โยนความผิด

🚫 **จะไม่เป็น:**
- Hero โรแมนติกที่ไม่มีระบบ
- เล่าเรื่องดึงน้ำตาเรียกกระแส
- ใช้ความสงสารแทนความรับผิดชอบ

### 1.4 IRONMAN Combination & Application

| Archetype | ใช้กับงาน |
|-----------|-----------|
| RULER     | อธิบายระบบ / ความโปร่งใส / กติกา |
| CREATOR   | แสดงเทคโนโลยี / นวัตกรรม / UX |
| HERO      | ดูแลลูกค้า / ตอบสนองในวิกฤต |

### 1.5 Archetype ที่ห้ามใช้เด็ดขาด

⚠️ ถ้างานใด "รู้สึก" เข้าข่ายเหล่านี้ ให้ถือว่า **ไม่ใช่ Lottery Plus**

| Archetype | เหตุผลที่ห้าม |
|-----------|--------------|
| OUTLAW     | เราไม่ล้มระบบ — เราสร้างระบบใหม่ |
| JESTER     | เราไม่เล่นกับความหวังของคน |
| INNOCENT   | เราไม่โลกสวย — รู้ความจริงของตลาด |
| CAREGIVER (ล้วน ๆ) | เราไม่ใจดีแบบไร้มาตรฐาน |

## 2. Brand Positioning — จุดยืน

### 2.1 Statement (immutable)

> "เราคือความหวังของคนจะรวย"

**หลักคิด:** จุดยืนที่แข็งแรง = จุดชนะในตลาด

### 2.2 Winning Zone Framework

วิเคราะห์ 3 แกนตัดกัน — จุดที่ทั้ง 3 แกนตัดกัน = Winning Zone

```
CUSTOMER DESIRES × OUR STRENGTHS × COMPETITOR STRENGTHS → WINNING ZONE
```

**Zone อื่นที่ต้องหลีกเลี่ยง:**
- **Risky** — ลูกค้าอยาก + คู่แข่งเก่ง แต่เราไม่เก่ง
- **Losing** — เราเก่ง + คู่แข่งเก่ง แต่ลูกค้าไม่ต้องการ
- **Non-sense** — เราเก่ง + ลูกค้าอยาก แต่ไม่ตรงตลาด

### 2.3 What Customers Want

- โอกาสถูกรางวัลที่ 1 — แต่ไม่ได้ต้องการแค่ลอตเตอรี่
- ความหวังที่รู้สึกปลอดภัย
- ระบบที่ไม่ต้องระแวง
- ประสบการณ์ที่ง่าย ไม่ซับซ้อน
- แบรนด์ที่ "ดูแลความหวังอย่างจริงจัง"

### 2.4 What We Do Best

- Personal Branding ของคุณนอท
- ทำให้ความหวังเป็นเรื่องจริงจัง
- ออกแบบระบบโปร่งใส ตรวจสอบได้ อธิบายได้
- สื่อสารด้วยความบันเทิงแต่ไม่กลบความถูกต้อง
- ยืนข้างผู้คน แม้ต้องชนระบบเดิม

→ **เราไม่ใช่ "ผู้ขาย" แต่เป็น "ผู้ดูแลโอกาส"**

### 2.5 What Competitors Do Best

| ผู้เล่น | จุดแข็ง | จุดอ่อน |
|---------|---------|---------|
| #1 แผงลอตเตอรี่ทั่วไป | เข้าถึงง่าย คุ้นเคย ราคามาตรฐาน | ประสบการณ์ไม่สม่ำเสมอ ไม่โปร่งใส ไม่มีบริการหลังขาย |
| #2 แพลตฟอร์มออนไลน์ | สะดวก รวดเร็ว มีเทคโนโลยี | ความเชื่อใจไม่แข็งแรง ภาพลักษณ์เน้นขายมากกว่าดูแล |

### 2.6 Our Winning Zone

เป็นแบรนด์ลอตเตอรี่ที่:
- ลูกค้ารู้จัก "เจ้าของแบรนด์" ได้
- ดูแลความหวังด้วยความถูกต้อง
- ประสบการณ์ง่าย + สบายใจ
- ยืนข้างผู้ใช้งานอย่างชัดเจน

ในอุตสาหกรรมที่คนเคยไม่เชื่อใจ → คู่แข่งตามยาก ต้องใช้ ระบบ + ความตั้งใจ + ความเชื่อใจ + จุดยืน พร้อมกัน

## 3. Customer Archetypes — ต้นแบบพฤติกรรมลูกค้า

**หลักการ:** ลูกค้า 1 คน = หลาย archetype ผสม แต่มี 1 archetype เด่นสุด

### 3.1 INNOCENT — ผู้มองหาความหวังที่ปลอดภัยและจริงใจ

มองลอตเตอรี่เป็น **"โอกาสของความหวัง"** ไม่ใช่การพนัน

| ด้าน | รายละเอียด |
|------|-----------|
| Motivation | อยากมีหวังให้ชีวิตดีขึ้น · มีโอกาสเปลี่ยนชีวิต |
| ต้องการจากเรา | ปลอดภัย / โปร่งใส / ระบบเชื่อถือได้ |
| 🚫 ห้าม | ข้อความที่ทำให้เข้าใจผิด · ภาพลวงตา · ขายฝันเกินจริง |
| พฤติกรรม | ซื้อเป็นครั้งคราว · ติดตามผลรางวัลอย่างตั้งใจ · ให้ความสำคัญกับความถูกต้องของระบบ |

### 3.2 EXPLORER — ผู้แสวงหาโอกาสและเส้นทางใหม่

ชอบลองสิ่งใหม่ สนใจประสบการณ์ที่ให้ความหวังที่ดีกว่า

| ด้าน | รายละเอียด |
|------|-----------|
| Motivation | หาเลขใหม่ · ค้นหาโอกาส · ใช้เทคโนโลยีใหม่ |
| ต้องการจากเรา | ระบบใช้ง่าย / ทันสมัย / feature ช่วยเข้าใจข้อมูล |
| 🚫 ห้าม | สื่อสารแบบเก่า · วิถีเดิม ๆ · platform ดูซับซ้อน |
| พฤติกรรม | ทดลอง feature ใหม่ · สำรวจระบบ · เปรียบเทียบ platform |

### 3.3 EVERYMAN — คนธรรมดาที่ต้องการความถูกต้อง

⭐ **กลุ่มลูกค้าหลักสุด** — ไม่ต้องการความตื่นเต้น ต้องการความถูกต้อง + ง่าย + สะดวก

| ด้าน | รายละเอียด |
|------|-----------|
| Motivation | เข้าถึงง่าย · ใช้สะดวก · ไม่ยุ่งยาก |
| ต้องการจากเรา | ระบบเข้าใจง่าย / ขั้นตอนไม่ซับซ้อน / ประสบการณ์ราบรื่น |
| 🚫 ห้าม | ภาษาซับซ้อน · ศัพท์เทคนิคมากเกินไป |
| พฤติกรรม | ซื้อเป็นประจำ · ใช้ตามขั้นตอนเดิม · ให้ความสำคัญกับความสะดวก |

### 3.4 OUTLAW — ผู้ต่อต้านระบบเดิมและความไม่ถูกต้อง

ตั้งคำถามกับระบบเดิม ไม่เชื่อคำสวยหรูจนกว่าจะเห็นหลักฐานโปร่งใส

| ด้าน | รายละเอียด |
|------|-----------|
| Motivation | ต้องการความจริง · ระบบโปร่งใส |
| ต้องการจากเรา | ข้อมูลตรวจสอบได้ / ระบบเปิดเผย / Proof ชัดเจน |
| 🚫 ห้าม | พูดเกินจริง · ใช้คำโฆษณา |
| พฤติกรรม | ถามคำถามเชิงลึก · ตรวจสอบข้อมูล · เปรียบเทียบ platform อื่น |

### 3.5 Common Ground ของทั้ง 4 Archetype

แม้แรงจูงใจต่างกัน แต่ทุกคนต้องการสิ่งเดียวกัน:
- **ความหวังที่มีความรับผิดชอบ**
- **ระบบที่เชื่อถือได้**

⚠️ ต้องสื่อสารให้เหมาะกับแต่ละ archetype **โดยไม่สูญเสีย Brand Identity**
