## 0. TL;DR — Rules Digest (อ่านบล็อกนี้ก่อนตัดสินใจทุกครั้ง)

**Brand belief:** "ที่ทำอยู่เพราะมันถูกต้อง"

**Vision Statement (quote ตรง ๆ ห้ามแก้):**
> "เราเชื่อในความถูกต้อง เราจึงมุ่งมั่นสร้างการเปลี่ยนแปลงผ่านประสบการณ์ของลูกค้า เพื่อเติมเต็มความหวังและสร้างความสุขที่คนไทยควรได้รับ"

**Hierarchy of Authority (สูง → ต่ำ):**
`VISION > MISSION > VALUES > POLICY > KPI`
- ขัดกัน → เลือกระดับบน เสมอ แม้ KPI จะดีขึ้น

**4 Values:**
1. **FAIR FOR TRUST** — ถูกต้อง 3 ระดับ (กฎหมาย / ศีลธรรม / ความรู้สึกลูกค้า) · Trust เสีย = งานล้มเหลวทันที
2. **ENTERTAINER** — บันเทิงอย่างรับผิดชอบ · อยู่ใต้ Trust เสมอ
3. **INTEGRITY** — ตรงไปตรงมา · ระบบผิด = บริษัทรับผิด ไม่มีข้อแก้ตัว
4. **SIMPLIFY** — ง่ายต่อการเข้าใจ / ใช้งาน / ตรวจสอบ

**4 Missions:**
1. **CUSTOMER IMPACT** — "ดีขึ้น" ต้องวัดได้ ไม่ใช่ความรู้สึก
2. **ENTERTAINMENT** — สนุกแบบไม่ทำลายสติ ไม่กระตุ้นความโลภ
3. **DISRUPTION** — สร้างระบบใหม่ที่โปร่งใส ไม่ใช่ลัดขั้นตอน
4. **TOGETHER** — ไม่หาย ไม่เงียบ ไม่โยนภาระ

**Decision frameworks (ใช้ก่อนรับงาน/ออกแบบ touchpoint):**
- **Opportunity Check (#01)** — Vision? + Trust? + Customer Impact? → ตอบ "ไม่" 1 ข้อ = ไม่ทำ
- **Experience Check (#02)** — Clarity? + Responsibility? + Respect? → ตอบ "ไม่" 1 ข้อ = ไม่ทำ

**Red Flags (ห้ามเด็ดขาด — ปรากฏซ้ำตลอดเอกสาร):**
- เร่งเร้าความโลภ / กดดันการตัดสินใจ / ใช้บันเทิงเร่งยอด
- บิดเบือนความจริง / คำสวยปกปิดปัญหา / หนีความรับผิดชอบ
- Outlaw disruption / ลัดขั้นตอนกฎหมาย / ใช้คำ "Disrupt" อ้างทำเรื่องเสี่ยง
- ทิ้งลูกค้า/ทีมในสถานการณ์ยาก / ใช้คำ "Together" สวย ๆ แทนแก้ปัญหา
- KPI/ความพึงพอใจ/คำชม ที่ไม่ใช่ Impact จริง

## 1. Brand Core

แกนแท้ที่กำหนด: เราเชื่ออะไร, ให้ความสำคัญกับอะไร, ตัดสินใจอย่างไร, อยากสร้างโลกแบบไหน

**ความเชื่อหลัก:** "ที่ทำอยู่เพราะมันถูกต้อง"
- ความหวังต้องมีมาตรฐานรองรับ + มีคนรับผิดชอบ
- ความไม่ถูกต้อง ≠ เรื่องปกติ
- ระบบที่ดี = ทำให้ความหวังปลอดภัยและมีคุณค่า

⚠️ **Immutable** — ห้ามเปลี่ยน ห้ามตีความใหม่ ใช้เป็นหลักตัดสินใจทุกครั้ง

## 2. Brand Vision

### 2.1 Statement (immutable)

> "เราเชื่อในความถูกต้อง เราจึงมุ่งมั่นสร้างการเปลี่ยนแปลงผ่านประสบการณ์ของลูกค้า เพื่อเติมเต็มความหวังและสร้างความสุขที่คนไทยควรได้รับ"

⚠️ สื่อสารด้วยประโยคนี้เท่านั้น — ห้ามแก้ ห้ามย่อ ห้ามตีความใหม่ตามบริบทงาน

### 2.2 Positioning

เราไม่ได้ขายลอตเตอรี่ — เราเลือกสร้างการเปลี่ยนแปลงด้วยการทำสิ่งที่ถูกต้อง เพื่อส่งมอบความหวัง + ความสุขให้ลูกค้า

### 2.3 Meaning Breakdown

| Layer | Keyword | ความหมายเชิงปฏิบัติ |
|-------|---------|---------------------|
| WHY  | เชื่อในความถูกต้อง       | ยืนบนหลักการชัดเจน — ถูกต้องทั้งตามขั้นตอน + "ใจคน" · ทุกการตัดสินใจตั้งต้นจากความเที่ยงตรง โปร่งใส เป็นธรรม |
| HOW  | เชื่อในการเปลี่ยนแปลง    | ไม่หยุดอยู่กับที่ · พัฒนาระบบโปร่งใส เข้าใจง่าย ตรวจสอบได้ ด้วยข้อมูล + เทคโนโลยี เพื่อสร้างมาตรฐานใหม่ |
| WHAT | เชื่อในประสบการณ์ลูกค้า | ทุก experience สะท้อน: ใส่ใจ / ง่าย / สบายใจ / "เขาได้สิ่งที่ควรได้" |

## 3. Brand Values (4 ข้อ)

ค่านิยม = นิสัยและพฤติกรรมในการอยู่ร่วมกันในองค์กร สู่การเป็นหนึ่งเพื่อสื่อสารสู่สาธารณะ

### 3.1 FAIR FOR TRUST — ความถูกต้องและความยุติธรรม

ความถูกต้อง = สิ่งที่ต้องเกิดขึ้นจริง ไม่ใช่คำประกาศ · เป็นคุณค่าที่แบรนด์ไม่เคยต่อรอง

**3 ระดับของความถูกต้อง:**
1. ตามกฎหมาย
2. ตามศีลธรรม
3. ต่อความรู้สึกของลูกค้า

**Trust = พื้นฐานของแบรนด์:**
- ระบบต้องโปร่งใส
- ตรวจสอบได้
- รับผิดชอบเมื่อเกิดความผิดพลาด

⚠️ **Trust เสีย → งานนั้นล้มเหลวทันที**

### 3.2 ENTERTAINER — ผู้ให้ความบันเทิงที่มีความรับผิดชอบ

ความหวังควรมาพร้อมความสุขเล็ก ๆ ในแต่ละวัน · การสื่อสาร/ประสบการณ์ของแบรนด์เต็มไปด้วยความสนุก อารมณ์ดี เป็นกันเอง · ความบันเทิง = วิธีเชื่อมใจคน ไม่ใช่แค่สีสัน

**กฎ:** ลอตเตอรี่ = ความบันเทิง ≠ เครื่องมือเร่งการตัดสินใจ

**ความบันเทิงต้องไม่:**
- กระตุ้นความโลภ
- ทำลายสติของลูกค้า
- สร้างความคาดหวังเกินจริง

💡 ถ้าต้องอธิบายยืดยาว = ระบบยังไม่ง่ายพอ

### 3.3 INTEGRITY — ความซื่อสัตย์ จริงใจ ตรงไปตรงมา

สื่อสารโปร่งใส ตอบตรง ไม่ทำให้ผู้ใช้ต้องคาดเดา · ความซื่อสัตย์ = มาตรฐานที่อยู่ในระบบ ไม่ใช่ภาพลักษณ์

**กฎ — ห้าม:**
- บิดเบือนความจริง
- ใช้คำสวยหรูปกปิดปัญหา
- หนีความรับผิดชอบเมื่อผิดพลาดจริง

⚠️ **ระบบผิด = บริษัทรับผิด ไม่มีข้อแก้ตัว**

### 3.4 SIMPLIFY — ทำให้ง่าย

หลักคิด: "เรื่องสำคัญควรเข้าใจง่าย" · ออกแบบทุกกระบวนการให้ชัดเจน เป็นมิตร ตั้งแต่ซื้อ → ตรวจ → รับบริการ

**ระบบที่ดีต้องง่าย 3 ทาง:**
- ง่ายต่อการเข้าใจ
- ง่ายต่อการใช้งาน
- ง่ายต่อการตรวจสอบ

💡 **"UX-UI + Content ต้องทำให้คนโง่ที่สุดในโลกใช้และเข้าใจการสื่อสารได้"** — เป็นคำเตือนใจมาตรฐานความง่าย ไม่ใช่คำดูถูกผู้ใช้

## 4. Brand Missions (4 ข้อ)

ภารกิจปฏิบัติการ ใช้ตรวจสอบงานทุกระดับ

### 4.1 CUSTOMER IMPACT — ทำให้ชีวิตลูกค้าดีขึ้นจริง

**กฎ:** "ดีขึ้น" ต้องวัดได้จริง ไม่ใช่ความรู้สึก

**ผลลัพธ์ที่นับเป็น Impact:**
- ความเสี่ยงของลูกค้า ↓
- ความชัดเจน ↑
- ความกังวล ↓
- ความสามารถควบคุมสถานการณ์ ↑

🚫 **Red Flag:**
- ความพึงพอใจ ≠ Impact
- คำชม ≠ ผลลัพธ์
- ความรู้สึกดีชั่วคราว ≠ ชีวิตดีขึ้น

### 4.2 ENTERTAINMENT — ความบันเทิง

**กฎ:** สร้างประสบการณ์ที่สนุก แต่ไม่ทำลายความรับผิดชอบ

**แนวทาง:**
- ลอตเตอรี่ = ความบันเทิง 1 รูปแบบ ไม่ใช่แค่ธุรกรรม
- เป็นประสบการณ์การลุ้นรางวัล "ที่มีขอบเขต"
- ไม่ทำลายสติหรือศักดิ์ศรีลูกค้า
- Entertainment อยู่ใต้ Trust เสมอ

🚫 **Red Flag:**
- เร่งเร้าอารมณ์ความโลภ
- กดดันการตัดสินใจของลูกค้า
- ใช้ความบันเทิงเป็นเครื่องมือเร่งยอด

### 4.3 DISRUPTION — กล้าสร้างการเปลี่ยนแปลงด้วยความถูกต้อง

**กฎ:** Disruption = สร้างระบบใหม่ที่โปร่งใส + ยุติธรรมกว่าเดิม

**แนวทาง:**
- Disrupt เพื่อแก้ปัญหาที่ผิดมานาน
- ไม่ Disrupt เพื่อเรียกความสนใจ
- ความเร็ว + ความรับผิดชอบ ต้องมาคู่กัน

🚫 **Red Flag:**
- Outlaw Disruption (disrupt นอกกฎหมาย)
- ลัดขั้นตอนกฎหมาย
- ใช้คำว่า "Disrupt" อ้างกระทำสิ่งเสี่ยง

### 4.4 TOGETHER — อยู่เคียงข้างลูกค้าและทีมในทุกสถานการณ์

**หลักการ:** ไม่หาย ไม่เงียบ ไม่โยนภาระ — ทั้งวันที่ระบบมีปัญหา / ลูกค้ากังวล / ทีมกดดัน

**แนวทาง:**
- ตอบรับ + ตอบสนองความกังวลทันที
- ยืนเคียงข้าง สร้างความมั่นใจในการเดินหน้า
- รับผิด + รับชอบ อย่างซื่อสัตย์

🚫 **Red Flag:**
- ใช้คำว่า "Together" สวย ๆ แทนการแก้ปัญหา
- ปล่อยให้ลูกค้าหรือทีมรับความเสี่ยงลำพัง
- อยู่ด้วยแค่ตอนดี วิ่งหนีตอนต้องรับผิดชอบ

## 5. Mission Implementation

Mission ถูกแปลสู่การปฏิบัติผ่าน 4 ช่องทาง:
1. Guideline to Opportunity
2. Brand Experience Design
3. Decision Flow
4. Governance System

### 5.1 Guideline #01 — Brand Opportunity Framework

ก่อนรับโอกาส/ไอเดียใด ๆ ต้องผ่าน 3 คำถาม:

```
IDEA → VISION CHECK → TRUST CHECK → CUSTOMER IMPACT → OPPORTUNITY
```

| # | คำถาม |
|---|-------|
| 1 | สอดคล้องกับ Brand Vision? |
| 2 | ทำให้ Trust ของแบรนด์แข็งแรงขึ้น? |
| 3 | เพิ่มคุณค่าให้ลูกค้า? |

⚠️ **ตอบ "ไม่" แม้ 1 ข้อ = ไม่ใช่โอกาสของแบรนด์**

### 5.2 Guideline #02 — Brand Experience Design

ทุก Touchpoint ของแบรนด์ ต้องไม่ใช่เรื่องบังเอิญ + ต้องมีคนรับผิดชอบ

**3 คำถามที่ทุก Touchpoint ต้องตอบ:**

| Principle | คำถาม |
|-----------|-------|
| CLARITY        | ลูกค้าเข้าใจสิ่งที่กำลังเกิดขึ้นหรือไม่? |
| RESPONSIBILITY | ลูกค้ารู้สึกว่ามีคนรับผิดชอบหรือไม่? |
| RESPECT        | ลูกค้าตัดสินใจได้อย่างมีสติหรือไม่? |

⚠️ **ตอบ "ไม่" แม้ 1 ข้อ = ไม่ใช่สิ่งที่แบรนด์จะทำ**

### 5.3 Constitutional Rule — Hierarchy of Authority

```
VISION > MISSION > VALUES > POLICY > KPI
```

⚠️ **ถ้าระดับล่างขัดระดับบน → เลือกระดับบนเสมอ แม้ KPI จะดีขึ้น**

**ตารางตัดสินใจ:**

| สถานการณ์                  | การตัดสินใจ                     |
|----------------------------|---------------------------------|
| KPI ขัด Values             | เลือก Values                    |
| Policy ขัด Mission         | เลือก Mission                   |
| Campaign ขัด Vision        | หยุด Campaign ทันที + เลือก Vision |

**Example:** เพิ่มยอดขายด้วยการใช้คำที่ทำให้เข้าใจผิด
- ผลลัพธ์: ยอดขายเพิ่ม แต่ Trust ลด
- การตัดสินใจที่ถูก: **หยุด Campaign ทันที**
